# Gamer Maldito – Sistema de Loja

## Apresentação do Projeto

Este projeto é um **Sistema de Loja** desenvolvido por alunos do 3º ano do Ensino Médio Técnico, com fins educacionais. O objetivo é simular um sistema comercial real, aplicando conceitos de programação orientada a objetos, banco de dados relacional, padrões de projeto e boas práticas de desenvolvimento.

O sistema foi desenvolvido ao longo do ano letivo, com rodízio de alunos a cada bimestre. Por isso, a **organização, clareza e documentação** são essenciais para garantir a continuidade e evolução do projeto.

Atualmente, o sistema conta com **todas as funcionalidades básicas** implementadas e testadas, incluindo cadastro de produtos, clientes, vendas com itens e processamento de pagamentos.

---

## Tecnologias Utilizadas

- **Java 21** – linguagem principal
- **Maven** – gerenciamento de dependências e build
- **PostgreSQL** – banco de dados relacional
- **JDBC** – conexão e operações com o banco
- **Padrões de projeto**: DAO (Data Access Object), Singleton, Polimorfismo
